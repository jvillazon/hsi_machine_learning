# Hyperspectral Machine Learning Analysis
Code for machine learning analysis on hyperspectral images acquired using SRS. Images from Laboratory of Optical Bioimaging and Spectroscopy under Dr. Lingyan Shi @UCSD.

---

## 🚀 Integrated Analysis Pipeline

For complete end-to-end documentation on:
1. Converting segmentation masks (TIFF) or Xenium single-cell CSVs into standardized `Vertices_JSON` `.parquet` tables,
2. Quantifying multi-modal, SRS chemical unmixing, and morphological metrics,
3. Running non-parametric group statistics (Kruskal-Wallis, Dunn's + BH FDR, Cliff's Delta, Van Elteren) and exporting publication plots (Violins/Bars with replicate dots and significance brackets),

See the **[Integrated Pipeline Documentation](file:///c:/Users/jvill/Documents/GitHub/hsi_machine_learning/integrated_pipeline/README.md)**.
